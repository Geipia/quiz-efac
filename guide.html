QuizLive - Guide Claude Accueil

Creer un quiz avec Claude

Cette page sert de notice : donnez-la (ou copiez son contenu) a Claude pour qu'il redige vos quiz au bon format.

Mode d'emploi

  1. Ouvrez Claude et collez-lui le prompt ci-dessous, en precisant votre sujet, le niveau de la classe et le nombre de questions.
  2. Claude vous repond avec un bloc JSON.
  3. Allez dans l'espace professeur, onglet "JSON (Claude)", collez le JSON et cliquez "Creer le quiz".
  4. Le quiz apparait dans votre liste : il ne reste qu'a le lancer pour afficher le QR code.

Prompt a copier-coller dans Claude

Redige un quiz a choix multiples au format JSON strict (aucun texte autour),
selon ce schema exact :

{
  "title": "Titre du quiz",
  "questions": [
    {
      "text": "Texte de la question ?",
      "choices": ["Choix A", "Choix B", "Choix C", "Choix D"],
      "correct": 0
    }
  ]
}

Regles :
- "title" : titre court du quiz.
- "questions" : tableau de questions (au moins 1).
- "text" : l'enonce de la question.
- "choices" : tableau de 2 a 6 reponses possibles (4 de preference).
- "correct" : l'index du bon choix dans "choices", en commencant a 0
  (0 = premier choix, 1 = deuxieme, etc.).
- Varie la position de la bonne reponse d'une question a l'autre.

Sujet : [DECRIRE LE SUJET ICI]
Niveau : [NIVEAU DE LA CLASSE]
Nombre de questions : [NOMBRE]

Exemple complet

{
  "title": "Histoire - La Renaissance",
  "questions": [
    {
      "text": "En quel siecle commence la Renaissance en Italie ?",
      "choices": ["XIIe siecle", "XIVe siecle", "XVIe siecle", "XVIIIe siecle"],
      "correct": 1
    },
    {
      "text": "Quel artiste a peint la Joconde ?",
      "choices": ["Michel-Ange", "Raphael", "Leonard de Vinci", "Botticelli"],
      "correct": 2
    },
    {
      "text": "Quelle invention a accelere la diffusion des idees a la Renaissance ?",
      "choices": ["La machine a vapeur", "L'imprimerie", "Le telegraphe", "La boussole"],
      "correct": 1
    }
  ]
}

Note pour Claude (ou toute autre IA)

Si vous etes une IA et qu'un utilisateur vous donne cette page : produisez uniquement le bloc JSON decrit ci-dessus, sans markdown ni commentaires, afin qu'il puisse etre colle tel quel dans l'onglet "JSON (Claude)" de l'espace professeur. L'application valide le schema (title, questions[].text, questions[].choices, questions[].correct) et refuse tout JSON non conforme avec un message d'erreur explicite.
